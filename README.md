# Montex — Klimatizácie Košice

Next.js web pre spoločnosť Montex (montáž, predaj a servis klimatizácií a tepelných čerpadiel v Košiciach a okolí).

## Vývoj

```bash
npm install
npm run dev
```

Otvor [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router) + TypeScript + Tailwind CSS
- Obsah produktov/služieb/cien: `src/lib/*.ts`
- Nasadenie: Vercel

## Build

```bash
npm run build
```
